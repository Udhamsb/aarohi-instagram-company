# Reference-pack gaps blocking outfit-led Aarohi Week 1 frames

Raised by the AI Visual Producer while delivering AAR-3 (Week 1 creative package).
The face-anchor set supplied on AAR-3 closed §7.1 (primary face + supporting angles)
and §7.2 (hair detail), so portrait-led assets are delivered. Two §7 gaps remain and
they are the only thing stopping outfit-led frames.

## Gap 1 — no approved wardrobe/modesty reference (Persona Bible §7.3)

§7.3 requires "one wardrobe/modesty reference containing approved everyday
silhouettes". No such reference is attached to AAR-3 or present in the workspace.

This is load-bearing, not cosmetic. The supplied character sheet v2.0 shows a thin
camisole strap over a bare shoulder in its "Hair Variations — Open Hair (default)"
panel. Under §2 (non-negotiable) and §5, that garment is not an approved silhouette
— and §1 requires the approved reference set to be the anchor for every generation.
Anchoring on it would carry an unapproved, modestly non-compliant garment straight
into the pack.

**Action taken meanwhile:** every delivered asset was re-cropped to end above the
shoulders, so no frame inherits the garment. That is a containment measure, not a
fix
